Data Analytics · Sports Media

F1 × Drive to Survive

Shipped
PythonOLS RegressionVADER NLPGoogle TrendsNielsen

Quantified how Netflix's Drive to Survive reshaped U.S. Formula 1 fan demographics and viewership from 2017–2024. Built an OLS regression model across 96 monthly observations controlling for COVID, organic growth, and search interest. Code was AI-generated; the model design and interpretation were mine.

Role
  • Group Lead: data pipeline, regression modeling, sentiment analysis, visualization
Key outputs
  • +312K viewership lift attributed to DTS era (p < 0.01, R² = 0.66)
  • Female fan share tripled 8% → 25% with r = 0.98 correlation
  • VADER sentiment analysis confirming traditional vs. new fan divergence

Code written with AI assistance and run by me. The analytical decisions were mine: which controls to include, how to read the regression output, what the sentiment divergence actually meant.

Marketplace Analytics · AI Agents

Amazon Category Intelligence

Shipped
PythonpandasSerpAPIClaude Agent SDKmatplotlib

Pulled 160 live Amazon listings across five search terms through a third-party API, built the normalization layer, and put a natural-language query agent on top, then spent as long testing where it breaks as building it. Code was AI-generated; I ran it, debugged it, and made every analytical call.

Role
  • Solo: API integration, data normalization, brand resolution, analysis, agent design, failure testing
Key outputs
  • White-label sellers hold 31% of the category shelf, more than Shark and Bissell combined
  • Review volume predicts demand ~2× better than search rank (ρ = +0.56 vs −0.29)
  • 9 of 72 products on "cordless" queries are corded; Shark fields only 3 true cordless stick vacuums
  • 7 documented agent failures, including 2 errors in my own analysis the agent surfaced

I don't write code from scratch. I direct AI to build it, then read, run and debug it myself. Here that meant catching two bugs in my own pipeline: a rank column I'd misread, and a category filter excluding Dyson for having short product titles.

07How I work

myapproach.

Working through real problems teaches you more than any classroom. Here's how I think and operate.

Let's work together → Download resume ↓

Start with the Why

Before jumping to solutions, I obsess over the problem. Who's affected, what's broken, and why it matters: that's where good products are actually born.

Own the Ambiguity

Not having all the answers doesn't slow me down. I break fuzzy goals into sharp requirements, align stakeholders early, and keep the team moving even when the path isn't obvious yet.

Ship Fast, Learn Fast

I'd rather test a rough idea with real users than polish something in isolation. Test, tweak, repeat.

Let Data Challenge My Assumptions

Gut instinct gets you to a hypothesis. Data tells you if you're right. I treat every metric as a question worth asking.

Tradeoffs Are the Job

Every decision comes with tradeoffs. Scope, time, quality: you rarely get all three. I make those calls clearly, communicate them honestly, and stand by them.

Keep the Right Voices in the Room

The best outcomes come from having the right people around the table, aligned on goals, clear on priorities, and bought into the core of what's being built.
